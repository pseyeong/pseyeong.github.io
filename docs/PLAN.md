# 기획

## 1. 서비스 개요

- **한 줄 정의**: 가진 재료로 만들 수 있는 요리를 찾고, 1인분에 얼마 드는지까지 보여주는 자취생 레시피 서비스
- **이름**: 자취한끼 (가칭)
- **형태**: 모바일 화면에 맞춘 반응형 웹. 관리자 페이지만 PC 화면 기준
- **차별점**: 재료 기반 추천, 1인분 단가 표시, 가격대 필터, 대체 재료 안내
- **이용 권한**: 열람과 검색은 누구나, 저장과 작성은 로그인 필요
- **만드는 사람**: 1인 개발, 프론트엔드 경험 있음, 백엔드 경험 없음

## 2. 기술 스택

- Next.js (App Router, TypeScript) + Tailwind CSS
- Supabase: DB(Postgres), 로그인(카카오·구글), 이미지 저장(Storage)
- Vercel 배포
- 레시피 상세·목록·재료별·가격대별 페이지는 검색 노출을 위해 서버에서 렌더링

## 3. 사이트맵

```
/                         홈
├─ /search                재료 검색 결과 (예: /search?q=계란,양파)
├─ /recipes               전체 레시피 목록 (가격대·조리시간·조리도구 필터)
│   ├─ /recipes/[id]      레시피 상세
│   ├─ /recipes/new       레시피 작성 (로그인 필요)
│   └─ /recipes/[id]/edit 레시피 수정 (작성자만)
├─ /ingredients/[name]    재료별 레시피 모음 (검색 유입용)
├─ /budget/[range]        가격대별 모음 (검색 유입용, 예: /budget/under-3000)
├─ /my                    마이페이지 (로그인 필요)
│   ├─ /my/saved          저장한 레시피
│   ├─ /my/recipes        내가 쓴 레시피
│   └─ /my/settings       닉네임 수정, 로그아웃, 탈퇴
├─ /login                 카카오·구글 로그인
├─ /about, /terms, /privacy
└─ /admin                 관리자 (관리자 역할만)
    ├─ /admin/recipes         레시피 목록, 숨김·공개, 등록, CSV 일괄 등록
    ├─ /admin/recipes/new     레시피 등록 (PC 양식)
    ├─ /admin/ingredients     재료 가격표
    ├─ /admin/substitutes     대체 재료 쌍
    └─ /admin/pending         기타 재료 후보
```

- 모바일 하단 탭: 홈, 검색, 작성, 마이
- 검색엔진 노출: 홈, 레시피 상세, 목록, 재료별, 가격대별
- 검색엔진 제외: /search, /my, /login, 작성·수정, /admin
- 비로그인 상태에서 저장·작성을 누르면 /login을 거쳐 원래 페이지로 복귀

## 4. 핵심 정책

### 4-1. 재료

- 검색과 레시피 작성 모두 **등록된 재료 중에서 자동완성으로 선택**한다.
- 재료마다 별칭을 둔다 (계란=달걀, 파=대파). 어느 쪽으로 입력해도 같은 재료가 나온다.
- 소금, 간장, 식용유 같은 **기본 양념**은 따로 표시하고 재료 검색 매칭에서 제외한다.
- 작성 중 목록에 없는 재료는 **기타 재료**로 직접 입력할 수 있다. 단가 계산에서 빠지고, 관리자의 "기타 재료 후보"에 쌓인다.

### 4-2. 재료 검색 결과

- 입력한 재료와 많이 겹치는 순으로 정렬한다.
- 카드에 보유 현황과 부족한 재료를 보여준다. 예: "4개 중 3개 보유 · 햄만 더 있으면 돼요"
- 대체 재료로 만들 수 있는 레시피도 결과에 포함하되, 정확히 일치하는 레시피 아래에 따로 묶고 "쪽파 대신 대파로 가능"처럼 표시한다.

### 4-3. 단가

- 재료마다 기준 단위(g, ml, 개)와 단위당 가격을 가격표에 저장한다.
- 1인분 단가 = (재료별 사용량 × 단위당 가격의 합) ÷ 인분 수
- 상세 페이지에 "1인분 약 2,150원"과 재료별 금액, 처음 장볼 때 드는 비용(남는 재료 포함)을 보여준다.
- 추정치라는 점과 가격 기준일을 함께 표시한다.
- 기타 재료가 섞인 레시피는 "일부 재료 제외" 표시를 붙인다.
- 1인분 단가는 레시피에 계산값으로 저장해 두고(필터·정렬용), 재료 가격이 바뀌면 그 재료를 쓰는 레시피만 다시 계산한다.
- 작성자는 사용량을 기준 단위(g, 개)로 입력하고, 화면에 보일 분량("1/2대", "1큰술")은 표시용으로 따로 적는다.

### 4-4. 대체 재료

- 재료 단위로 한 번만 등록한다. "설탕 → 알룰로스"를 등록하면 설탕이 들어가는 모든 레시피에 나온다.
- 방향이 있다. "A 대신 B"를 한 방향씩 저장한다.
- 비율과 한 줄 설명을 함께 저장한다. 예: "설탕 1 : 알룰로스 1.3, 단맛이 약해요"
- 태그 세 가지: 없을 때 / 더 싸게 / 더 가볍게
- 레시피 상세에서 대체 가능한 재료 옆에 "대체" 버튼을 두고, 누르면 아래에서 올라오는 시트에 대체 재료, 비율, 설명, 단가 차액을 보여준다.
- 단가 기본 표시는 원래 재료 기준. 대체 재료는 차액만 보여준다.

### 4-5. 닉네임

- 가입 시 "형용사 + 음식 + 숫자 4자리" 조합으로 자동 부여한다 (예: 배고픈감자4821). 겹치면 다시 뽑는다.
- 소셜 로그인의 실명과 프로필 사진은 가져오지 않는다.
- /my/settings에서 수정할 수 있고, 입력하는 동안 중복 여부와 규칙 위반을 바로 알려준다.
- 규칙: 2~12자, 한글·영문·숫자만, 공백과 특수문자 불가, 영문 대소문자는 같은 것으로 취급
- 중복은 화면 검사와 별개로 **DB 고유 제약**으로 최종 차단한다 (대소문자 무시).
- 금칙어 목록(욕설, "관리자", "운영자" 등)을 둔다.
- 변경 후 30일 동안은 다시 바꿀 수 없다.

### 4-6. 관리자

- profiles에 역할(user/admin)을 두고 admin만 /admin에 접근한다. 화면에서 숨기는 것과 별개로 DB 권한(RLS)에서도 막는다.
- 운영자가 직접 올리는 레시피는 "자취한끼 공식" 계정으로 표시한다.
- 레시피는 공개/숨김 상태를 가진다. 숨김은 검수 전 초안이나 부적절한 글 처리에 쓴다.
- 재료 가격을 30일 넘게 갱신하지 않으면 가격표에서 강조 표시한다.
- CSV로 여러 레시피를 한 번에 등록할 수 있다 (등록 전 미리보기).
- 레시피에 출처 입력란을 둔다 (공공데이터 등 출처 표기용).

## 5. 화면별 기능

| 화면 | 주요 기능 |
|---|---|
| 홈 | 재료 검색창, 추천 배너, 바로가기 8개(가격대·시간·도구), 인기 레시피(가로 스크롤), 최신 레시피 |
| 재료 검색 결과 | 선택한 재료 칩(추가·삭제), 일치순 카드, 보유 현황 배지, 부족한 재료, 대체 재료로 가능한 레시피 |
| 레시피 목록 | 가격·시간·도구 필터 칩, 정렬(가격 낮은순·최신순·인기순·조리시간 짧은순), 2열 카드 |
| 레시피 상세 | 대표 사진, 제목, 작성자·시간·인분·도구, 1인분 단가와 장보기 비용, 재료별 금액, 대체 버튼, 기타 재료, 기본 양념, 조리 순서, 저장, 공유 |
| 대체 재료 시트 | 대체 재료별 태그, 차액, 비율, 설명 |
| 레시피 작성·수정 | 대표 사진, 제목, 인분, 조리시간, 도구, 재료 자동완성과 사용량·표시용 분량, 기타 재료 직접 입력, 예상 단가 실시간 표시, 단계별 설명과 사진 |
| 마이 | 닉네임, 저장·작성 수, 저장한 레시피/내가 쓴 레시피 탭 |
| 로그인 | 카카오·구글, 랜덤 닉네임 안내, 약관 동의 문구 |
| 설정 | 닉네임 수정(실시간 검사, 랜덤 뽑기), 약관, 로그아웃, 탈퇴 |
| 관리자 | 요약, 레시피 관리, 레시피 등록(PC), 재료 가격표, 대체 재료, 기타 재료 후보 |

## 6. 데이터 구조

| 테이블 | 주요 항목 |
|---|---|
| profiles | id(auth.users 참조), nickname(고유, 대소문자 무시), role(user/admin), nickname_changed_at, created_at |
| ingredients | id, name(고유), aliases(배열), category, unit(g/ml/개), unit_price, is_basic(기본 양념), price_updated_at |
| recipes | id, author_id, title, description, cover_image, servings, cook_minutes, tool, price_per_serving(계산값), is_partial_price(일부 재료 제외), status(public/hidden), source, created_at |
| recipe_ingredients | id, recipe_id, ingredient_id(기타 재료면 null), custom_name(기타 재료 이름), quantity(기준 단위 사용량), display_amount(표시용 분량), sort_order |
| recipe_steps | id, recipe_id, step_no, content, image |
| saves | user_id, recipe_id, created_at (둘의 조합이 고유) |
| ingredient_substitutes | id, ingredient_id(원래 재료), substitute_id(대체 재료), ratio, tag(없을 때/더 싸게/더 가볍게), note |

### 권한(RLS) 원칙

- 공개 레시피, 재료, 대체 재료: 누구나 읽기
- 레시피·재료·단계 쓰기: 본인이 작성한 레시피만, 관리자는 전체
- saves: 본인 것만 읽기·쓰기
- profiles: 닉네임은 누구나 읽기, 수정은 본인만. role은 본인이 바꿀 수 없음
- ingredients, ingredient_substitutes 쓰기: 관리자만
- **모든 테이블에 RLS를 켠다.** 빠뜨리면 남의 데이터를 누구나 수정할 수 있게 된다.

## 7. 첫 버전에서 뺀 것

댓글, 후기 사진, 팔로우, 랭킹, 알림, 작성자 프로필 페이지, 주간 식단과 장보기 목록, 회원 관리·통계·신고 처리, 대체 재료를 골라 전체 단가를 다시 계산하는 기능, 큰술·한 줌 같은 단위 자동 환산

## 8. 초기 데이터

- 재료 가격표 100~150개 (직접 입력, 공공데이터 aT KAMIS 농산물 가격 참고 가능)
- 대체 재료 30~50쌍
- 레시피 50개: 공공데이터(식품안전나라 조리식품 레시피 DB 등)와 직접 정리한 기본 요리. 블로그 글과 사진을 복사하지 않는다. 공공데이터는 이용 조건과 출처 표기 조건을 확인하고 쓴다.

## 9. 수익화 (출시 이후)

- 순서: 재료·조리도구 제휴 링크 → 트래픽이 쌓이면 광고 → 규모가 되면 브랜드 협찬
- 제휴 링크를 달 때는 수수료를 받는다는 문구를 표시한다.
