# 자취한끼(가칭) 개발 문서

자취생 레시피 서비스의 기획, 디자인, 개발 순서를 모은 폴더입니다.
이 폴더(`docs`)를 프로젝트 폴더 최상위에 그대로 넣어 주세요.

## 읽는 순서

1. `PLAN.md` — 서비스 기획: 사이트맵, 정책, 화면별 기능, 테이블 구조
2. `DESIGN.md` — 디자인 기준: 색, 글꼴, 글자 크기, 버튼, 화면 구성 규칙
3. `STEPS.md` — 단계별 작업 지시문 (1단계~9단계)
4. `design/` — 화면 원본
   - `design/mobile/` 최종 디자인 9개 (이 화면대로 구현)
   - `design/admin/` 관리자 화면 6개 (구성만 참고, 색·글꼴은 DESIGN.md 기준으로)

## Claude Code에 처음 입력할 말

```
docs 폴더의 README.md, PLAN.md, DESIGN.md, STEPS.md를 읽고
STEPS.md의 1단계만 진행해줘. 끝나면 무엇을 했는지와 내가 확인할 것을 알려줘.
```

한 단계가 끝나면 직접 화면을 확인한 뒤 "2단계 진행해줘"처럼 다음 단계를 요청합니다.

## design 폴더의 HTML에 대해

- 디자인 도구에서 내보낸 원본이라 브라우저에서 바로 열면 화면이 그려지지 않습니다. 코드 편집기에서 읽는 용도입니다.
- `<x-dc>` 안의 마크업과 inline style이 실제 화면 구조와 수치입니다.
- `{{이름}}`은 파일 아래쪽 `<script>`의 `renderVals()`가 돌려주는 값이 들어가는 자리이고, `<sc-for>`는 반복, `<sc-if>`는 조건 표시입니다.
- 안에 든 레시피, 가격, 닉네임은 모두 예시 데이터입니다.
- 사진 자리는 회색 상자로 표시되어 있습니다.
