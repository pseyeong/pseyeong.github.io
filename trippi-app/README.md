# TRIPPI App Prototype

이 디렉터리는 TRIPPI 앱 화면 구현을 위한 React Native/Expo 샘플 코드입니다.

## 설치

1. Node.js 설치 후, `trippi-app` 디렉터리로 이동합니다.
2. `npm install` 또는 `yarn install` 실행합니다.

## 실행

- `npm start`
- `npm run ios` 또는 `npm run android`

## 화면 구성

- 홈: 메인 캘린더 요약, 진행 중 여행, 동반자 D-day
- 캘린더: 월/주 토글, 일정 목록, 날짜별 다이어리 요약
- 여행: 여행 목록, Day별 루트, 지도/장소 표시
- 다이어리: 날짜별 기록, 감정 태그, 첨부 미리보기
- 동반자: 초대 코드, 공유 정책, 연결 상태
